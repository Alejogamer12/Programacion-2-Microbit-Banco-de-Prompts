## Plantilla para crear nuevos prompts

Quiero crear un programa sencillo en MicroPython para BBC micro:bit llamado **[NOMBRE]**.

Objetivo: **[QUÉ QUIERO QUE HAGA]**.

Entrada: **[BOTÓN, MOVIMIENTO, LUZ U OTRA ENTRADA]**.

Proceso: **[QUÉ DEBE HACER EL PROGRAMA]**.

Salida: **[QUÉ DEBE MOSTRAR O HACER]**.

El código debe ser corto, sencillo y fácil de explicar para un estudiante de grado 11 que está aprendiendo programación. Debe usar solamente funciones compatibles con BBC micro:bit y no debe agregar cosas innecesarias.

Después del código explica cada parte con palabras sencillas, indica cómo probarlo en una micro:bit real y menciona posibles errores sin inventar resultados de pruebas.
