## Propósito

Mi propósito con este trabajo es aprender a crear un programa sencillo para una BBC micro:bit usando un prompt bien explicado. Escogí hacer un dado digital porque es una idea fácil de entender y me permite practicar varias cosas que estamos trabajando en Programación 2.

Quiero que al agitar la micro:bit aparezca un número del 1 al 6, como si fuera un dado normal. La idea no es solamente conseguir un código que funcione, sino también entender qué hace cada parte, probarlo personalmente en una micro:bit y corregirlo si encuentro algún problema.

También quiero aprender a escribir mejores instrucciones para obtener resultados más claros y que después otra persona pueda utilizar mi prompt y entender fácilmente para qué sirve.

## Proyecto principal: Dado Digital D6

Funcionamiento:

1. La micro:bit queda esperando.
2. El estudiante agita la placa.
3. El acelerómetro detecta el movimiento.
4. El programa genera un número al azar entre 1 y 6.
5. El número aparece en la matriz LED.
6. El programa vuelve a esperar otro lanzamiento.

**Entrada:** agitar la BBC micro:bit.  
**Proceso:** generar un número entero al azar entre 1 y 6.  
**Salida:** mostrar el resultado en la matriz LED.
